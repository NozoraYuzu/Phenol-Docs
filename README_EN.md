# Phenol-Docs
A set of descriptions regarding related services. Each service has one dedicated folder.

Please note that while explanations are available in both Japanese and English, the Japanese version serves as the standard, with the English version provided for reference; this is because it is not possible to fully absorb the differences that arise from translation.

Please direct any questions or inquiries regarding this document to the [Google Form](https://docs.google.com/forms/d/e/1FAIpQLSdOlVykJcnkZH-F5ChSo4Vu3xpomN5HC6xWmJ4VaJfNTyicLA/viewform?usp=dialog).
